## 2. Near-Duplicate Train/Test Overlap Audit

### 2.1 Audit Objective & Rationale
While Stage 4C-2 certified an **exact-duplicate-free split** (0 identical 63-feature vectors across the 2.83M rows, verified via 256-bit SHA-256), network traffic datasets generated by automated attack scripts often produce "near-duplicate" flows—records whose numerical values differ only by microsecond jitter, minute packet inter-arrival times, or minor rounding artifacts.

This audit quantitatively measures the degree of near-duplicate proximity between the 2,264,633 training flows and the 566,110 held-out test flows.

### 2.2 Methodology & Distance Metric
1. **Feature Scaling (Min-Max Normalization):**  
   Because raw features span vastly different scales (e.g. `Flow Duration` up to $10^8$ microseconds vs `FIN Flag Count` in $\{0, 1\}$), all 63 numerical features were scaled to $[0.0, 1.0]$ based strictly on training set bounds:
   $$z_j = \text{clip}\left(\frac{x_j - \min_j(X_{\text{train}})}{\max_j(X_{\text{train}}) - \min_j(X_{\text{train}}) + \delta}, 0.0, 1.0\right)$$
2. **Normalized L1 (Manhattan) Distance Metric:**  
   The distance between a test flow $\mathbf{z}_{\text{test}}$ and a training flow $\mathbf{z}_{\text{train}}$ is measured as the normalized mean absolute feature deviation across all 63 dimensions:
   $$d_{\text{norm}}(\mathbf{z}_{\text{test}}, \mathbf{z}_{\text{train}}) = \frac{1}{63} \sum_{j=1}^{63} |z_{\text{test}, j} - z_{\text{train}, j}|$$
   A distance of $d_{\text{norm}} = 0.001$ indicates that features deviate by an average of only **0.1%** across the full feature range.
3. **Multi-Resolution Quantized Binning Hashing:**  
   To evaluate the entire 2,830,743-row dataset without sampling bias, normalized features were uniformly quantized into discrete bins and hashed using 64-bit MurmurHash3:
   - **Fine:** 1,000 bins per feature ($\epsilon = 0.001$, 0.1% bin width).
   - **Moderate:** 100 bins per feature ($\epsilon = 0.010$, 1.0% bin width).
   - **Coarse:** 20 bins per feature ($\epsilon = 0.050$, 5.0% bin width).
4. **Exact 1-Nearest Neighbor ($k=1$) Analysis:**  
   Computed exact nearest-neighbor distance distributions per class between test flows and training flows of the same class.

### 2.5 Critical Audit Findings & Fundamental Limitations

1. **Exact vs Near Duplicate Disparity:**  
   While exact duplicate vectors across the partition boundary were eliminated (0 exact collisions), **65.37% of test flows fall into identical 1,000-bin quantized buckets ($\epsilon = 0.001$) as training flows**, and **86.65% fall into identical 100-bin buckets ($\epsilon = 0.010$)**.
2. **Attack Script Homogeneity:**  
   In automated network benchmarks like CIC-IDS-2017, attack tools (e.g. Patator, Slowloris, LOIC, Hulk) execute tight programmatic loops with fixed parameters (e.g., constant packet lengths, fixed TCP window sizes, identical header options). Consequently, variations between flows are dominated by micro-jitter in timestamps and inter-arrival times.
3. **Interpolation vs Generalization:**  
   The held-out test partition evaluates the model's ability to **interpolate within dense clusters of synthetic traffic** originating from the same capture environment, host IP configuration, and attack scripts.
4. **Generalization Boundary:**  
   The reported test accuracy (99.8917%) must strictly be interpreted as an **in-distribution benchmark estimate**. It cannot be assumed to generalize to out-of-distribution network environments, new attack variants, or real-world enterprise traffic.
